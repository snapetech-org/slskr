The shipped Web UI now lets each browser choose an interface language. Primary navigation is translated in twelve locales with English fallback. The Downloads and Uploads views also translate transfer statuses, empty states, bulk retry/cancel/remove choices, and download-mode toggles. Arabic translated labels carry local right-to-left metadata; remaining screens and help text stay English.
