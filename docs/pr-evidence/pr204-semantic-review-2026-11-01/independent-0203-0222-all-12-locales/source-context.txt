## Cell context map

- `203` `Advanced`: System navigation tab label: Advanced settings pane (System.jsx).
- `204` `Advanced Filters`: Accessible label/title of the sliders button that opens search-result filters (SearchResultControls.jsx).
- `205` `Advanced Search Filters`: Heading of the advanced search-filter modal (SearchFilterModal.jsx).
- `206` `Advanced privacy and anonymity features`: Subheader for security/privacy/anonymity controls on Adversarial Settings (AdversarialSettingsView.jsx).
- `207` `Adversarial`: Short name of the adversarial-security profile area; exact page warns it is for repressive regimes or active surveillance and all options are disabled by default.
- `208` `Adversarial Features Unavailable`: Error header when adversarial-security options are unavailable; this is a security feature, not an opposing/contradictory feature.
- `209` `Adversarial Profile`: Label for the selected security/threat profile in the adversarial-security form.
- `210` `Adversarial Resilience Overview`: Heading for resilience against adversarial attacks in the same security overview.
- `211` `Adversarial Settings`: Settings tab for the security controls described by the page warning.
- `212` `Adversarial Settings Not Configured`: Empty-state header when no adversarial-security configuration is present.
- `213` `Adversarial features are advanced security options designed for users in adversarial environments. They are disabled by default and require explicit configuration.`: Explanation that these are advanced security options for repressive regimes or users facing active surveillance; disabled by default and require explicit configuration.
- `214` `Adversarial features are not configured on this server`: Error text when this server has no adversarial-security configuration.
- `215` `Adversarial settings updated successfully`: Success toast after saving the security settings.
- `216` `Affinity Score:`: Numeric peer affinity percentage displayed alongside a separate trust score, message count, and opinion count.
- `217` `After import`: Automation cadence for a media-server rescan after successful library import, not customs import.
- `218` `Against:`: Label before the top evidence against a synthetic SongID hypothesis; means counter-evidence.
- `219` `Age:`: Descriptor freshness value displayed as total minutes followed by “minutes”; means elapsed age.
- `220` `Agent Mode`: Primary-navigation item for the app’s agent profile/mode.
- `221` `Aggregated Opinion Results`: Heading above weighted/unweighted aggregates and consensus results for peer opinions.
- `222` `Agreement:`: Numeric opinion-agreement measure calculated as one minus standard deviation divided by five; adjacent text says lower standard deviation means higher agreement.
