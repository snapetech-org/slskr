## Hindi CIDR field cross-reference

`API key CIDR allowlist` labels the `apiKeyCidr` field; the visible neighboring label is `API CIDRs`. Hindi translates that visible label as `API सीआईडीआर` and this accessible name as `API कुंजी सीआईडीआर अनुमति सूची`, retaining API in Latin and transliterating CIDR consistently.

## German compound notes

The German catalog already uses `API-Schlüssel` (`API Key`) and `API-Token` (`API Token`). The fresh targets `API Schlüssel-CIDR-Zulassungsliste` and `API Ratenbegrenzungsfenster in Sekunden` omit that hyphen after the initial abbreviation; the proposed forms use the same local pattern.
